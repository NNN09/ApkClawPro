# 会议纪要整理

目标：把用户提供的会议转写文本（或聊天记录）整理为一份结构化会议纪要。

## 步骤

1. 通读全部内容，识别出：参会人（如提到）、讨论主题、结论、待办事项、争议点。
2. 按以下模板输出纪要（调用 finish 返回）：

```
## 会议纪要
- 时间/主题：
### 关键结论
1. ...
### 待办事项
- [ ] 事项 — 负责人（如有） — 截止时间（如有）
### 遗留问题
1. ...
```

## 注意

- 只依据用户提供的内容整理，不要编造未提到的结论或待办。
- 原文含糊的地方标注"（原文未明确）"。
- 不需要操作设备上的任何 App；直接整理并 finish。

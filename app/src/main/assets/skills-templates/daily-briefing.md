# 每日简报

目标：生成一份简短的晨间简报并回传给用户。

## 步骤

1. 查询日历：调用 query_calendar(date=今天, days=1)，列出今天的日程。
2. 查询电量：调用 query_battery，电量低于 20% 时提醒用户充电。
3. （可选，用户配置过渠道时）打开邮件/IM App 用 UI 自动化查看未读数，只统计数量不读内容。
4. 汇总为简报并 finish：

```
## 今日简报
- 日程：N 项（列出时间和主题）
- 电量：xx%（需要充电时提醒）
- 待关注：...
```

## 注意

- 简报控制在 150 字以内。
- 没有日程就说"今天暂无日程"，不要编造。
- 步骤 3 如遇登录墙直接跳过，不要尝试登录。
